Bug 1 🔴 — Fornecedor Simples Nacional gerando crédito de ICMS indevido
Problema: A verificação de regime do fornecedor existe para PIS/COFINS mas foi omitida para ICMS. Empresas do Simples Nacional não destacam ICMS na NF (LC 123/2006, art. 23), portanto o comprador não pode se creditar.

Localizar este bloco no código:

typescript
// ❌ REMOVER / SUBSTITUIR ESTE BLOCO:
if (isInputOrResale) {
  if (buyer?.taxRegime === 'REAL' || buyer?.taxRegime === 'PRESUMIDO') {
    creditIcms = icms;
  }
}
Substituir por:

typescript
// ✅ NOVO BLOCO CORRETO:
if (isInputOrResale) {
  if (buyer?.taxRegime === 'REAL' || buyer?.taxRegime === 'PRESUMIDO') {
    const supplier = suppliers.find(s => s.id === quote.companyId);
    if (supplier?.taxRegime !== 'SIMPLES') {
      creditIcms = icms;
    }
    // Se fornecedor for Simples: creditIcms permanece 0
  }
}
Bug 2 🟡 — Ativo Imobilizado recebendo crédito de ICMS integral (deveria ser 1/48)
Problema: FIXED_ASSET está agrupado com insumos em isInputOrResale, recebendo crédito total no mês. Pela LC 87/1996, art. 20 §5°, o crédito de ativo imobilizado é apropriado em 48 parcelas mensais (controlado no livro CIAP).

Localizar esta linha:

typescript
// ❌ LINHA ERRADA — FIXED_ASSET não deve estar aqui:
const isInputOrResale = ['INDUSTRIAL_INPUT', 'RESALE', 'FIXED_ASSET'].includes(quote.itemUseType || 'INDUSTRIAL_INPUT');
Substituir toda a lógica por:

typescript
// ✅ SEPARAR insumo/revenda de ativo imobilizado:
const isInput = ['INDUSTRIAL_INPUT', 'RESALE'].includes(quote.itemUseType || '');
const isFixedAsset = quote.itemUseType === 'FIXED_ASSET';

// Crédito ICMS — Insumo/Revenda: imediato
if (isInput) {
  if (buyer?.taxRegime === 'REAL' || buyer?.taxRegime === 'PRESUMIDO') {
    const supplier = suppliers.find(s => s.id === quote.companyId);
    if (supplier?.taxRegime !== 'SIMPLES') {
      creditIcms = icms;
    }
  }
}

// Crédito ICMS — Ativo Imobilizado: 1/48 por mês (LC 87/96 art. 20 §5°)
if (isFixedAsset) {
  if (buyer?.taxRegime === 'REAL' || buyer?.taxRegime === 'PRESUMIDO') {
    const supplier = suppliers.find(s => s.id === quote.companyId);
    if (supplier?.taxRegime !== 'SIMPLES') {
      creditIcms = icms / 48;
    }
  }
}
⚠️ Atenção: Atualizar também a variável isInputOrResale nos blocos de PIS/COFINS e IPI abaixo — substituir por isInput onde aplicável.

Bug 3 🟡 — Crédito de IPI não verifica regime do fornecedor
Problema: O crédito de IPI verifica apenas o regime do comprador, mas ignora se o fornecedor é Simples Nacional. Fornecedores do Simples não destacam IPI na NF, então o crédito não existe.

Localizar este bloco:

typescript
// ❌ REMOVER / SUBSTITUIR ESTE BLOCO:
if (buyer?.taxRegime !== 'SIMPLES' && quote.itemUseType === 'INDUSTRIAL_INPUT') {
  creditIpi = ipi;
}
Substituir por:

typescript
// ✅ NOVO BLOCO CORRETO:
const supplierForIpi = suppliers.find(s => s.id === quote.companyId);
if (
  buyer?.taxRegime !== 'SIMPLES' &&
  supplierForIpi?.taxRegime !== 'SIMPLES' &&
  quote.itemUseType === 'INDUSTRIAL_INPUT'
) {
  creditIpi = ipi;
}
